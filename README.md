# Back End - Junior

## Definition
Crea endpoints CRUD básicos con lenguajes como Node.js, Java o Python. Maneja peticiones HTTP, conecta a bases de datos simples y valida datos de entrada.

## Specific Project
API REST para una biblioteca (CRUD de libros, autores y préstamos) con autenticación básica por email/contraseña.

## Core Concepts
Métodos HTTP (GET, POST, PUT, DELETE), códigos de estado (2xx, 4xx, 5xx), JWT (firma y verificación), middleware de validación (Joi/Zod), ORM (Sequelize/TypeORM o Prisma), conexión a PostgreSQL/MySQL, variables de entorno (.env).

## Recommended Modern Technologies
Node.js 22 + Express o Fastify, o Python 3.12 + FastAPI (asíncrono), Prisma o Drizzle (ORM moderno), PostgreSQL 16, JWT con jsonwebtoken, Joi o Zod, dotenv + pino.
